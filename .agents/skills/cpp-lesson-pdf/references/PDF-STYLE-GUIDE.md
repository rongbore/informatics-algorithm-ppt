# PDF 样式规范（经过原版 15 页反向测量）

## 版心和层级

- A4 白底单栏；参考 PDF 版心 x≈56.7–538.6 pt，左右各约 20 mm。上部正文约 y=53 pt；下边距须根据内容保留，不能超页。
- 页 1 主标题：23.91pt 深蓝（居中）；副标题：10.91pt 青绿（居中）。不加单独封面。
- 一级章节：14.35pt 深蓝；二级小节：11.96pt 青绿；正文：10.91pt 黑色；标签/注意标题：10.91pt 赭橙。
- 正文自然换行、首行缩进约两个汉字，行距约 16pt。避免每个小节强制分页。
- 字体尽量匹配 FandolSong Regular/Bold；英文 Latin Modern，数学 Computer Modern；C++ 代码 Latin Modern Mono（9pt / 13.2pt）。

## 内容组件

- 重要规则：带较深顶条的浅色说明框；警示框仅用于错误陷阱，不用彩色盖过正文。
- 概念表：适中列宽、细分隔横线、克制的字体颜色。
- 算法图：TikZ 向量，直径约 8–10 mm 的圆节点，细蓝线与明显有向箭头；旁注可用橙色。
- 样例：左“输入”右“输出”双栏，浅蓝色表头和浅蓝白底，字符等宽且换行不丢失。
- 推导：优先列“步骤 / 当前状态 / 变化 / 结果”，数值着色只用于需强调的少量值。
- 代码：白色背景+细浅灰蓝边框，等宽字体约 9pt、行高约 13pt；不显示行号且不预留编号栏；关键字蓝、注释绿、字符串暖色。**含中文注释，必须在 PDF 可见**。

## LaTeX 实现约定

- 主样式 `templates/lesson-style.sty`；图形 `templates/diagram-styles.tex`。
- `minted` + Pygments `vs` 方案提供浅色编辑器语法高亮。TeX Live minted v3 有首遍 `<MINTED>` 占位符的情况，必须至少两遍编译和文本/截图检查。
- 代码从单独 `.cpp` 文件读取，可以用 g++ 直接编译，而不是在 LaTeX 中手动重打一份可能不一致的代码。
- 用户没有提出统一页数时按内容自然分页，**不能为追求页数压缩代码字号或略掉内容**。


## v1.3 数据可视化推导的版式

- 图不是装饰：**状态输入（蓝）→ 当前操作（橙）→ 更新成功（青绿）→ 错误与反例（红）**。每种颜色都应配文字标签，确保黑白打印仍然能辨认。
- 推荐示例图组件见 `examples/derivations/tree_knapsack_visual.tex`；表格必须展示旧值、候选值、合法性判断和更新后的值。不可达写 `-INF` 而不是默认 0。
- 树形背包：同页先画“u：已合并部分 → v：新子树（边费 w）”，接着给 j/k 枚举表，随后展示新的 DP 数组，最后用红色小框给正序反例；不要只把递推式放在一张卡片里。
- 适合图示的结构首选 TikZ：节点边不重叠；选择的节点或边在每一步保持固定坐标；图下给关键算式和文字解释；长表可跨页且重复表头，避免一个步骤的标题和图解分离。
- 推导数据原则上要从已确认的题目样例或程序校验的示例 JSON 来。引用脚本 `scripts/trace_dp_merge.py` 输出的表格后，仍需检查 PDF 的字体、上下间距、下标位置与清晰度。


## v1.3.2 用户指定覆盖项

虽然原始参考 PDF 的代码块曾使用灰色行号（上方仅作为历史测量记录），当前生成版统一**去除所有代码行号**。代码内容从代码框内部左侧正常起排，不保留数字栏或空白编号栏。

最终学生讲义中不得插入“排版说明”板块或任何介绍源码引入方式、代码配色、行号显示、构建/渲染流程的制作元说明。代码标题后直接呈现代码。若课程本身确实讲解排版知识，只有在用户明确要求时才将相关内容作为课程知识保留。
