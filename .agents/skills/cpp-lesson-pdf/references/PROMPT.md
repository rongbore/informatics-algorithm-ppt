# 统一提示词入口

本文件为向后兼容的入口。请优先完整读取：

- `MASTER-PROMPT.md`：内容生成和质量门槛
- `REVERSE-ENGINEERING.md`：从原 15 页讲义测量得到的精确风格参数与页码证据
- `PDF-STYLE-GUIDE.md`：视觉组件和颜色
- `CODE-COMMENT-RULES.md`：每题完整 C++ 代码与中文核心注释
- `QA-CHECKLIST.md`：编译与逐页验收

默认以“知识点讲解 → 课堂练习”为教学主线，每道题必须有完整可复制编译的 C++ 程序，并在最终 PDF 代码块中真实呈现中文关键注释。不能用 `<MINTED>` 等占位符代替代码。不能把未验证的程序标注为在线评测已 AC。


## v1.3.2 代码版式覆盖规则

最终 PDF 不得包含“排版说明”板块或解释源码引入/颜色显示/本地测试/渲染流程的元说明。C++ 代码区不显示任何行号，左侧不留编号 gutter；保留正常编辑器语法高亮、中文核心注释和完整代码。代码标题后直接进入代码框。
