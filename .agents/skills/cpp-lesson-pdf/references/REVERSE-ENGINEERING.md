## 逐页的结构证据

1. **第 1 页**：居中主标题/副标题 → 蓝色一级章节 → 青绿色小节 → 概念叙述 → 标题条说明框 → 蓝线四节点有向图 → 合法序列 → 术语表。

3. **第 3–4 页**：小根堆字典序、唯一性、DAG 路径 DP 的自然拓展，穿插图解、状态表、公式和复杂度。
4. **第 4–7 页**：题 25951《家族名册》：完整题面、样例左右分栏、题意概括、五步分析、队列变化、代码分模块、完整代码（第 6–7 页跨页）。
5. **第 7–9 页**：题 25952《任务编号排序》：字典序最小、无环判定、小根堆、关键代码分解和 42 行题解代码。
6. **第 9–12 页**：题 25953《确定卡片编号》：多组样例；强调拓扑序是“位置顺序”而最终输出是“数值按位置排列”；保留核心赋值流程表及 45 行代码。
7. **第 13–15 页**：题 25954《一路向东》：最长路径 DP 定义、状态转移、节点 dp 图、每一步转移表、完整代码。

## 应从原版提取的教学法（不是硬编码内容）

- 从生活场景引入，但定义准确且不冗长。
- 每个重要步骤都解释“为什么”，而不只罗列操作。
- 先讲清楚概念/状态，再将核心流程拆成少量代码块，最后给出**完整可运行代码**。
- 对样例进行真正的状态变化推导（队列、入度、dp 数组等），不能仅照抄样例输入输出。
- 对每道题保留“题面 → 题意概括 → 分步分析 → 推导表/图 → 代码模块 → 复杂度 → 完整代码”节奏。
- 图和表只在帮助理解状态时使用，矢量清晰，避免纯装饰。

## 不应伪造的能力

- 无法仅由 PDF 确定具体 LaTeX 宏、宏包配置或精确分页阈值。
- 源文件中表格/算法图未必都是同一绘图宏实现；本包通过一致的 TikZ/tcolorbox 组件实现等效视觉。
- 《拓扑排序课堂讲义.pdf》原有“AC 代码”的标注，不能自动推广为新生成题解已通过在线评测。
