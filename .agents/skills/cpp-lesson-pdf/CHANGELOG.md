# Changelog

## v1.2.0 — 2026-11-19

- 依据 15 页《拓扑排序课堂讲义》实测字体、字号、页边距、颜色、代码框与图表特征，不再凭主观视觉猜测。
- 新增教学母版 `references/MASTER-PROMPT.md`，逐题固定“题意→推导→模块→完整代码”的课程流程。
- 增加蓝、青绿、橙、浅红 4 种浅底标题条提示框与输入输出双栏样例。
- 将中文注释和标准 C++ 编辑器语法高亮作为必须正确渲染的需求。
- 修复 XeLaTeX minted v3 首遍可能输出 `<MINTED>` 占位符的问题（编译两遍、文档扫描，失败阻止交付）。
- 模板代码从独立 `.cpp` 文件读取，避免展示代码与待测试代码不一致。
- 增加 `analyze_reference.py` 和增强版 `validate.py`。
- 重新生成 3 页样例 PDF，确认 A4/中文核心注释/C++ 语法与 PDF 文本提取正常。

**提示**：这是风格复刻增强，不代表取得了原始 `.tex` 工程或实现逐页像素级相同。


## v1.3.0 — 2026-11-22

- 根据用户提供的六页《解析.pdf》新增八步深度解题分析和数据可视化推导规范。
- 引入状态定义/计算时机/逐行解读/合法性检查/逐格更新/误区反例/代码映射的教学闭环。
- 新增树形背包原地合并的可重复计算数据、示例 LaTeX/TikZ 图、Python `j/k` 转移表与正序错误反例。
- 在 `validate.py` 中加入状态表数值与反例自动复核；未增加运行时依赖。
- 保留原 15 页《拓扑排序课堂讲义》的蓝绿橙视觉体系；仅增强算法解释与可验证的数据图。
- 本次变更不包括将用户原始 PDF 上传仓库，不声称示意数据是官方测试样例，也不默认宣称新题解已 AC。

## v1.3.1 — 2026-11-22

- 新增 Kahn 拓扑排序队列和入度跟踪脚本，兼容 C++ 示例 FIFO 执行顺序，处理重复边、独立起点与有向环。
- 同一次计算同时生成 Markdown 推导表和 LaTeX 跨页长表，避免人工录入错误。
- 新增六节点 DAG 和含环反例、TikZ 示意图、可复用教学流程说明。
- 增加单元/边界测试，以及运行真实 C++17 程序比对预期输出的验证项。
- CI 校验两种数值推导：树形背包和拓扑排序；不改变已有 PDF 母版的主要颜色/版心。
