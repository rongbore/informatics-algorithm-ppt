# 单调队列：滑动窗口最大值

C++ 算法课 · CSP-J / GESP 进阶

**目标：** 看懂窗口变化、队列维护与最优解的由来。

---

# 问题与朴素思路

给定数组和窗口大小 `k`，输出每个长度为 `k` 的连续窗口最大值。

- 朴素解：每次遍历窗口，复杂度 `O(nk)`
- 思考：前一个窗口的信息能不能复用？

---

# 关键发现

当新元素 `x` 大于等于队尾元素时，旧队尾元素不可能再成为未来窗口的最大值。

因此维护 **下标递增、对应值严格递减** 的双端队列。

# 课堂预测

当新元素比队尾大时，为什么可以删除队尾？

<v-click>

因为新元素更大且更晚离开未来的窗口，旧队尾不再有竞争力。

# 复杂度与边界

- 每个下标最多入队一次、出队一次：`O(n)`
- 额外空间：`O(k)`
- 边界：`k=1`、`k=n`、全相等、全负数

---

# 总结与练习

- 队列保存的是 **下标**，不是只保存数值。
- 队首过期时删除；队尾不优时删除。
- 练习：把最大值改成最小值，哪些比较符号要调整？
