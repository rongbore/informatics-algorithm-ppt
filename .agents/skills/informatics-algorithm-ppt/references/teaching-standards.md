# Teaching standards
Default single lesson: 50 minutes. Warm-up 5, problem comprehension 7, naive approach 8, optimization 10, guided trace 10, coding 7, summary/exit ticket 3. Adapt to actual class length.

Student-facing deck: 12–18 slides for a 50-minute class, one idea per slide. Require at least two prediction questions, one boundary case, one misconception check, one transfer exercise. Teacher notes include objective, expected answer, possible wrong answer, time, and explanation prompt. Use approachable light theme and moderate cartoon motifs without distracting from algorithms.

For multi-lesson requests, plan each session separately. Do not imply that interactive HTML automatically retains all features in PDF/PPTX export.
