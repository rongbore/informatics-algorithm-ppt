# Curriculum planning guide
This is an instructional mapping, not a verbatim official exam syllabus. Verify against current CCF and GESP outlines when precise exam alignment is requested.

- Syntax stage: I/O, variables, types, assignment, branching, loops, arrays, strings, functions.
- Algorithm foundation: enumeration, simulation, sorting, prefix sums, binary search, elementary greedy.
- CSP-J / introductory competition: recursion, DFS/BFS, basic stacks/queues, elementary graph and DP.
- Advanced entry: graph algorithms, advanced DP, greedy proofs, number theory and data structures.
- Advanced stage: complex graph, optimization DP, segment trees, more advanced algorithm analysis.

Every generated deck must explicitly state prerequisites and target stage; topic placement can be adapted to the current official outline.
