# Visual grammar
| Family | Main visual | Required labels | Interaction |
|---|---|---|---|
| Sorting | indexed array, comparison bars | indices, values, swap reason | step, compare, reset |
| Binary search | sorted array and [L,R] | L, mid, R, predicate | predict half, step |
| Stack / queue | indexed boxes and active pointers | indices and values separately | push/pop trace |
| DFS / BFS | graph/tree + frontier | visited, frontier, current | expand one step |
| Dynamic programming | grid or state DAG | state definition, predecessor, transition | reveal one cell |
| Graph shortest path | nodes, edges, distance table | weights, INF, settled | relax one edge |

Always pair color with labels and explain what changed. Prefer stable layouts to moving the whole slide.
