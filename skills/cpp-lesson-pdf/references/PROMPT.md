# 可复用提示词：C++ 信息学课堂讲义

请作为 C++ 信息学竞赛教师、教材编辑和 XeLaTeX 排版工程师，以《拓扑排序课堂讲义.pdf》为视觉母版，制作新的 A4 中文 PDF 讲义。

## 版式
- A4 纵向，白底单栏，不单独制作封面，不自动添加日期、机构名、Logo。
- 主标题深蓝 #22598D，约 24pt；一级章节同色约 14.3pt；二级标题青绿 #18766E，约 12pt；分析/代码标题赭橙 #B4661D，约 11pt。
- 中文宋体（优先 FandolSong），正文约 10.9pt，代码约 9pt 等宽字。
- 代码框白底、浅灰蓝边、浅灰行号、编辑器风格关键字/注释/字符串高亮。
- 图解采用 TikZ 矢量图，节点、箭头与标签清晰，不得与文字重叠。

## 内容结构
一、知识点讲解：生活场景引入、术语、核心原理、步骤、手工模拟、代码分模块、易错点、拓展、复杂度。
二、课堂练习：逐题完整保留题面、输入输出、样例、约束、题意概括、思路分析（第一步/第二步…）、样例推导分析过程、代码分模块理解、复杂度、完整 C++ 参考代码。

## 准确性
- 不改动用户提供的题目约束和样例。
- 不擅自改变参考代码算法逻辑；如发现问题，明确指出后给出修正版。
- 图形数据必须与题目和推导一致。
- 不把未经在线评测的代码称为已通过 AC。

## 实现与验收
使用本 Skill 的 `templates/lesson-style.sty` 和 `templates/diagram-styles.tex`。完成 XeLaTeX 编译后渲染检查每页，核对标题、表格、代码和公式。必要时与原 PDF 的第 1、6、8 页进行视觉对比。不能宣称像素级复刻，除非完成逐页差异验证。
