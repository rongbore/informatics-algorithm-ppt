- 代码框白底、浅灰蓝边、浅灰行号、编辑器风格关键字/注释/字符串高亮。
- 图解采用 TikZ 矢量图，节点、箭头与标签清晰，不得与文字重叠。

## 题解代码中文核心注释（强制要求）
每一道练习题的完整 C++ 参考代码必须添加**中文核心注释**，注释必须真实显示在最终 PDF 的代码框内，不得只写在代码框外的讲解段落。

1. **关键变量与状态**：解释 DP 状态、数组、队列、图结构及其用途。
2. **初始化依据**：解释初始值、起点或无穷值的含义。
3. **核心算法与转移**：紧贴重要代码，解释为什么更新、如何保证正确性。
4. **关键判断与边界**：说明不可达、负权、取模、重复边、空输入、路径恢复等适用情况（仅在题目相关时使用）。
5. **结果输出**：解释答案的计算与输出意义。

注释使用简洁准确的中文，优先解释“为什么”，而不是逐行翻译语法。中等长度题解一般配置 5–12 条有价值的注释，复杂题可增加。保持 C++ 代码的原有缩进、语法高亮、行号和等宽字体。对于用户提供的参考代码，保留算法与变量命名；发现错误须先说明再修正。

### 注释示例
```cpp
// dp[v]：从起点到节点 v 的最长路径长度
// 只有 u 可达时，才允许从 u 向后继节点转移
if (dp[u] != NEG_INF) {
    dp[v] = max(dp[v], dp[u] + w); // 选择更长的路径
}
// 当前前驱处理完毕，更新后继节点剩余入度
if (--indeg[v] == 0) q.push(v);
```

**验收门槛**：逐题检查完整代码是否具有可见的中文核心注释；检查 XeLaTeX 渲染后的中文注释是否乱码、裁切、溢出或缺字。若 `listings` 无法稳定渲染 UTF-8 中文注释，必须调整排版实现，不得删除中文注释来规避问题。
