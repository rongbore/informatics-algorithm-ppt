# V3.0 implementation notes

## User contract
One PPTX upload remains the only required content input. Azure credentials are environment configuration, not user-uploaded content. The active Skill selects Azure with `-TtsProvider azure -AzureVoiceProfile coach_excited`.

## Azure voice A/B
Both auditions use Azure AI Speech `zh-CN-YunjianNeural`:
- `coach_excited`: `sports-commentary-excited`
- `coach_balanced`: `sports-commentary`

They are two Azure expression profiles, not separate vendors. SSML samples live in `voice_samples/`. Actual MP3 auditions require `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`. Never silently fall back to Edge/eSpeak. Human listening review is mandatory.

## Four source-bound DSU animations
`scripts/detect_dsu_deck_v30.py` checks the source deck sections. `scripts/build_dsu_v30_animations.py` creates 1080p/30fps state frames and preview MP4s with SHA-256 manifests for:
1. Relatives: five unions and final root comparison.
2. Fencing: source coordinates, two DSU groups, bounding rectangles and perimeters 40/10.
3. Food chain: 3n S/P/E representation; relation directions, contradiction and range checks.
4. Galaxy: directed queue append, old receiving-team size as offset, and weighted path compression.

Each state frame maps to one event ID in `prompts/dsu_animation_narration_v30.json`. Azure TTS creates measured phrase timings; `render_dsu_animation_chapters_v30.py` holds each verified state frame for the corresponding measured speech interval. `compose_full_course_v30.py` inserts the narrated chapters after slides 15, 21, 27 and 33, and rebases the SRT using the same offsets.

## Local prerequisites
- Windows + PowerPoint for source-faithful slide export.
- Python 3.10+, FFmpeg, FFprobe, Noto CJK fonts.
- `python -m pip install -r requirements-v2.4.txt`.
- Set `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION` locally or in GitHub Actions Secrets.

## Validation gates
- Python unit tests for SSML validity, missing-secret fail-closed behavior and all four animation chapters.
- Source PPTX hash, frame hashes, algorithm-specific assertions, 1080p/30fps, audio/video duration and full decode.
- Machine QA never sets `auto_approved=true`; a teacher must review pronunciation, emphasis, algorithm explanations and visual timing.

## Known limitation
The initial V3.0 state animations use discrete, narration-synchronized state frames rather than continuous object interpolation. They are real state-driven diagrams, not generative video. Azure MP3 auditions and full-course integration are blocked until valid Azure resource credentials are configured.
